# AXION X 8.20 — предварительная версия

- Отмена покупателем разрешена только при статусе PENDING, включая серверную проверку.
- Отправленные уведомления показываются только за последние семь дней. Нажатие открывает детали и удаление. Новые общие рассылки получают batchId для точного удаления всех получателей; для старых рассылок без batchId безопасно удаляется только выбранная запись.
- Серверный счётчик непрочитанных сообщений включает обычные и заказные сообщения, обновляется при входе в диалог и раз в 30 секунд.
- Быстрый старт продавца доступен до его первого сообщения, даже если покупатель уже написал.
- Добавлен множественный выбор совместимости при создании объявления, хранение в JSON compatibility и миграция. Редактирование и фильтрация каталога по новым сочетаниям ещё не интегрированы.

ВАЖНО: npm ci в среде подготовки не завершился до таймаута; type-check, lint и build НЕ подтверждены. Перед применением миграций сделайте резервную копию БД.
