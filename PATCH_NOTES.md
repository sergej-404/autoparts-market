# AXION X — точечные исправления

Изменены компоненты администрирования, карточки товара, профиль, чат, заголовок и авторизация. Добавлена конфигурация ESLint 9 и postinstall для генерации Prisma Client.

Внимание: исходный package-lock.json сохранён. После `npm ci` выполните `npm audit fix` для обновления Next.js и Zod в локальном lock-файле. `npm audit fix --force` не выполняйте: он переводит Prisma на 7.

Проверка после распаковки: `npm ci`, `npx prisma validate`, `npx prisma generate`, `npm run type-check`, `npm run lint`, `npm run build`, `npm audit`.

Автоматические проверки в среде подготовки не удалось выполнить: загрузка npm-пакетов завершилась по таймауту. Изменения React требуют локального тестирования. Секретные файлы `.env` и `.env.local` исключены из архива: перенесите их из собственной исходной копии проекта.
