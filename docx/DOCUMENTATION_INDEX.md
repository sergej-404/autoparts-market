# Индекс документации AXION X

Вся документация проекта хранится в `docx/`.

- `README.md` — актуальная карта проекта, стек, команды и release checklist.
- `EMAIL_AUTHENTICATION_STATUS.md` — фактическое состояние email OTP и требования к Resend.
- `SECURITY.md` — меры безопасности.
- `MIGRATION_RECOVERY.md` — особенности восстановления истории миграций и Neon.
- `VERCEL_BLOB_SETUP.md` — настройка хранилища изображений.
- `WEB_PUSH_SETUP.md` — настройка Web Push.
- `PRODUCTION_READINESS_AUDIT.md`, `AUDIT_STAGE_1.md`, `AUDIT_STAGE_2.md` — аудиты соответствующих итераций.
- `PERFORMANCE_COLD_START_DIAGNOSTICS.md`, `PERFORMANCE_IMPLEMENTATION_REPORT.md` — диагностика и отчёт производительности.
- `NOTIFICATIONS_STAGE_2.md` — настройки уведомлений.
- `STOCK_RESERVATION_RELEASE.md` — резервирование товарных остатков.
- `PATCH_NOTES.md`, `CHANGELOG_*.md`, `RELEASE_*.md`, `IMPLEMENTATION_NOTES.md` — исторические записи изменений.

Исторические документы сохранены для аудита и не переписываются задним числом. Актуальное состояние следует читать в `README.md` и тематических документах.
