# AXION X — изменения чата и категорий

## Что добавлено
- Кнопка «Написать продавцу» на странице товара для авторизованного пользователя (кроме владельца товара). Она открывает `/chat` с параметрами товара и продавца.
- Модели `ChatConversation` и `ChatMessage`, API создания/получения диалогов и отправки текстовых сообщений. Доступ к сообщениям ограничен участниками диалога.
- Публичный идентификатор пользователя `us-` + 6 цифр; поле включено в поиск получателя в панели уведомлений администратора.
- Эмодзи категорий центрированы, SVG-иконки заменены на эмодзи с резервными значениями.

## Перед запуском
1. Проверьте `DATABASE_URL` в окружении развертывания.
2. Примените миграции: `npx prisma migrate deploy`.
3. Обновите Prisma Client: `npx prisma generate`.
4. Проверьте типы и сборку: `npm run type-check`, затем `npm run build`.

## Известные ограничения
- Сообщения сохраняются в БД, но для получения новых сообщений без перезагрузки пока нет real-time/polling-подписки.
- Вложения-фотографии в чат пока не сохраняются сервером; отправка текстовых сообщений работает через API.
- Публичный ID имеет пространство из 1 000 000 вариантов; при создании выполняется проверка уникальности с повторными попытками.
- Установить зависимости и выполнить полноценную проверку сборки в этой среде не удалось (установка зависимостей превысила доступное время).
