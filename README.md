# AutoParts Market

Стартовая версия нового проекта каталога автозапчастей. Проект создан с нуля и не является копией BazarraNET.

## Стек

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

На этом этапе база данных, авторизация и серверная бизнес-логика намеренно не подключены.

## Запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

Проверки:

```bash
npm run type-check
npm run build
```

## Маршруты стартовой версии

- `/` — главная
- `/catalog` — каталог
- `/product/[id]` — карточка товара
- `/profile/settings` — настройки профиля
- `/favorites` — избранное
- `/notifications` — уведомления
- `/login` — вход
- `/register` — регистрация
- `/admin` — админ-панель
- `/moderator` — панель модератора
- `/chat/[sellerId]` — чат с продавцом

Сейчас полноценной функциональностью обладает главная страница; остальные маршруты являются подготовленными точками расширения.

## Дальнейшее развитие

Функциональность будет добавляться поэтапно без переписывания уже созданной основы:

1. Каталог и реальные карточки товаров.
2. Категории, подкатегории и динамические характеристики.
3. База данных и модель пользователей.
4. Роли USER / MODERATOR / ADMIN.
5. Регистрация и авторизация.
6. Добавление объявлений и загрузка до 10 фотографий.
7. Модерация.
8. Избранное и уведомления.
9. Чат с продавцом.
10. Административная и аналитическая части.
11. Подготовка production-развёртывания.
