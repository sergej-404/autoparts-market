# AXION X 8.18 — изменения

- Административные уведомления: внешний ID получателя `publicId` вместо внутреннего ID.
- Корзина и избранное: локальные ключи разделены по ID авторизованного пользователя; гостевой ключ отдельный. Старые общие ключи `axion_cart` и `axion_favorites` намеренно не переносятся, чтобы исключить смешивание данных разных аккаунтов.
- Профиль / Мои заказы: подтверждение безвозвратного удаления заказа через защищённый `DELETE /api/orders/[orderId]`. Каскадные связи Prisma удаляют позиции заказа и его сообщения.
- Чат: создание диалога сериализовано транзакционной блокировкой PostgreSQL по комбинации покупатель/продавец/товар. Это предотвращает дубли при параллельных запросах. Уже существующие дубли автоматически не удаляются, чтобы не терять переписку.

Проверка: архив ZIP проверен на целостность. `npm ci --offline` не завершился: пакет yocto-queue отсутствует в локальном кеше, поэтому `type-check`, `lint` и `build` не подтверждены.
